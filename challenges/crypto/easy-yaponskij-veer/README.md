# Японский веер (crypto/easy)

- Порт: `13410` (переопределяется через `PORT`; внутри контейнера `8080`)
- Флаг: только из env `CTF_FLAG`

## Запуск

```bash
CTF_FLAG='InnoCTF{...}' docker compose up -d --build
curl http://127.0.0.1:13410/
```

## Условие (для игроков)

**RU:** Из Токио пришли две разные карточки с одинаковой короткой печатью архива.
Убедите смотрителя, что печати действительно совпадают, и он откроет личное сообщение.

**EN:** Two different cards have arrived from Tokyo carrying the same short archive seal.
Convince the keeper that the seals really do match, and he will open the private message.

## Решение

Главная страница отдаёт `case_id` и полное определение формата печати: первые
24 бита `SHA-256(case_id || card_bytes)`. Печать короткая (24 бита), поэтому
ищем birthday-коллизию: генерируем короткие карточки `tokyo-card-<n>`, считаем
`SHA-256(case_id || card)[:3]` и храним первую карточку для каждого трёхбайтового
префикса. Коллизия ожидается после ~2^12 попыток (перебор до 2^20 с запасом).

Обе карточки Base64-кодируем и отправляем `POST /submit` c JSON
`{"first": ..., "second": ...}`. Сервер проверяет, что карточки различны, а
печати совпадают, и отдаёт флаг. Это ограниченное упражнение на коллизию
(birthday), а не поиск второго прообраза.
