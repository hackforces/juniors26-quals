# Греческий переводчик (crypto/medium)

- Порт: `13412` (переопределяется через `PORT`; внутри контейнера `8080`)
- Флаг: только из env `CTF_FLAG`

## Запуск

```bash
CTF_FLAG='InnoCTF{...}' docker compose up -d --build
curl http://127.0.0.1:13412/download/registry.json -o registry.json
```

## Условие (для игроков)

**RU:** Переводчик передал реестр печатей нескольких ведомств и зашифрованную записку.
Одна печать изготовлена с ошибкой. Найдите её и прочтите личное сообщение.

**EN:** The interpreter has handed over a registry of seals from several departments and an enciphered note.
One of the seals was made with a flaw. Find it and read the private message.

## Решение

Артефакт `download/registry.json` содержит список RSA-«печатей» (сертификатов ведомств) и
зашифрованную флагом записку. Целевой модуль (помечен `target`) был изготовлен с ошибкой:
он делит простой множитель с одним из других публичных модулей.

1. Считаем `gcd(n_target, n_i)` для каждого сертификата реестра; для одного из них НОД
   больше 1 — это и есть общий простой множитель, целевой модуль факторизуется.
2. `phi = (p-1)(q-1)`, приватная экспонента `d = e^(-1) mod phi`.
3. Разворачиваем 16-байтовый сессионный ключ: `key = wrapped^d mod n`.
4. Конструкция потока описана в самом JSON: гамма
   `SHA-256(key || nonce || counter_be_32)`, XOR с шифртекстом — получаем флаг.

Общий множитель, target ID, nonce и шифртекст генерируются из CTF_FLAG при старте контейнера.
Факторизация отдельных 320-битных модулей — не предполагаемый путь.

## Проверка решения

```bash

python3 solve.py registry.json # или локальный файл
```
