# Львиная грива (stego/hard)

- Порт: `13432` (переопределяется через `PORT`; внутри контейнера `8080`)
- Флаг: только из env `CTF_FLAG`

## Запуск

```bash
CTF_FLAG='InnoCTF{...}' docker compose up -d --build
curl http://127.0.0.1:13432/download/coast.png -o coast.png
```

## Условие (для игроков)

**RU:** Автопортрет с морского побережья пережил слишком много пересылок. Холмс просит изучить сам снимок,
а не его подпись. Заберите его здесь.

**EN:** A self-portrait from the sea coast has survived too many transfers. Holmes asks you to study the picture itself,
not its caption. Collect it here.

## Решение

`download/coast.png` — PNG 128×128 (RGB, без палитры) с текстовым чанком `tEXt` —
реставрационной заметкой: «красные волокна отмечают нужные синие; читайте их в
порядке развёртки. Нить была свёрнута терминалом побережья».

1. Парсим чанки PNG: размеры из `IHDR`, сжатые данные из `IDAT`. Распаковываем
   IDAT (zlib) — получаем сырые сканлайны (по фильтр-байту на строку + RGB-триплеты).
2. Карта выбора спрятана в красной битовой плоскости: пиксель «отмечен», если
   младший бит его красного канала равен `1` (внутри генератора — квадратичная
   маска `(x*x + y*y) % 7 == 3`, участнику формула не нужна: карта видна в
   red plane; выбирается ровно 2664 пикселя из 128×128).
3. У отмеченных пикселей снимаем младший бит синего канала в порядке строк,
   собираем биты в байты (MSB first).
4. Заголовок собранного потока указывает на zlib — распаковываем и получаем флаг.

Полезная нагрузка сжимается zlib, поэтому собранный поток начинается с
zlib-заголовка. Изображение генерируется из CTF_FLAG при старте контейнера.

