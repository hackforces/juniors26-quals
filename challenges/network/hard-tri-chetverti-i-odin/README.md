# Три четверти и один / Three Quarters and One (network/hard)

- Порт: `13417` (переопределяется через `PORT`; внутри контейнера `8080`, HTTP)
- Флаг: только из env `CTF_FLAG`

## Запуск

```bash
CTF_FLAG='InnoCTF{...}' docker compose up -d --build
open http://127.0.0.1:13417/download/quarters.pcap
```

## Условие (для игроков)

**RU:** Холмс нашёл фрагменты передачи, которую полиция сочла шумом
экспериментальной сети. Восстановите последнюю фразу отправителя.
Личная запись

**EN:** Holmes has found fragments of a transmission that the police dismissed
as noise on an experimental network. Recover the sender's last phrase.
Personal recording

## Решение

В записи — обычный фон экспериментального полигона (ARP, DNS, NTP, ICMP,
mDNS-анонсы, broadcast-системный лог, статус-страница коллектора и
TLS-подобные аплинки архива, суммарно ~120 КБ), внутри которого перемешаны
датаграммы телеметрии и передачи с префиксом `HQ/`.

1. Фильтруем UDP-payload с `HQ/`: управляющие датаграммы `HQ/CASE/<id>` и
   `HQ/SPEC/v1;data=3;parity=xor;encoding=base64;key=sha256(case:seq:slot)[0];
   missing=seq-mod-3` полностью задают протокол.
2. Группа = последовательность `HQ/<seq>/<slot>/`: три 4-байтовых блока данных
   (`0,1,2`) и XOR-блок чётности `P`. В каждой группе отсутствует блок
   `seq mod 3` — потеря намеренная, избыточность обязательна.
3. Снимаем однобайтовую маску `sha256("<case>:<seq>:<slot>")[0]` (XOR) с
   двух дошедших блоков и `P` (слот `P`), base64-декодируем.
4. Недостающий блок = `P XOR known0 XOR known1`.
5. Склеиваем блоки `0,1,2` по возрастанию seq, убираем нулевое дополнение —
   получается флаг.

Датаграммы перемешаны сидом от case-id; порядок восстанавливается по номерам
последовательностей, а не по порядку в файле.
