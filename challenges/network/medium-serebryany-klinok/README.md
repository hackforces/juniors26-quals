# Серебряный клинок / The Silver Blade (network/medium)

- Порт: `13418` (переопределяется через `PORT`; внутри контейнера `8080`, HTTP)
- Флаг: только из env `CTF_FLAG`

## Запуск

```bash
CTF_FLAG='InnoCTF{...}' docker compose up -d --build
open http://127.0.0.1:13418/download/night.pcap
```

## Условие (для игроков)

**RU:** На столе у инспектора лежит запись ночных обращений к городскому
справочнику. Один посетитель оставлял для Холмса след, но не в привычном виде.
Заберите личный файл

**EN:** On the inspector's desk lies a record of the night's queries to the
city directory. One visitor left a trail for Holmes, but not in the usual form.
Collect your personal file

## Решение

Дамп — ночная сессия городского справочника (~17 КБ, ~70 пакетов): HTTP-портал
baker.city, TLS-подобный аплинк, ICMP и десяток декой-DNS (A/AAAA/MX/TXT/PTR).
Среди них — экзофильтрация:

1. В записи — серия UDP/DNS-запросов (порт 53) с именами вида
   `<nn>-<data>.silver.baker`, где `nn` — двузначный порядковый номер куска.
   Ответы на них NXDOMAIN и не важны: данные — в самих запросах.
2. Вырезаем метки в порядке номеров (каждая встречается один раз — вопрос
   в ответах сжат указателем), отбрасывая префикс `nn-`. Декой-имена в той же
   зоне (`patrol-report`, `duty-log`) не матчатся — у них нет числового
   префикса.
3. Склеиваем куски: получается Base32-текст (нижний регистр; в DNS-именах
   используются только `[a-z2-7]`), выравниваем `=` до кратности 8.
4. `base32`-декодирование даёт флаг.

Тонкость: Base32, а не Base64, и данные — в самих DNS-метках (subdomain-
экзофилтрация), а не в ответах.
