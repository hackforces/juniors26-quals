# The Second Stain (reverse/medium)

- Порт: `13430` (переопределяется через `PORT`; внутри контейнера `8080`)
- Флаг: только из env `CTF_FLAG` — байткод журнала генерируется при старте
  контейнера
- Уровень: medium (tags: juniors, sherlock-2050)

## Запуск

```bash
CTF_FLAG='InnoCTF{...}' docker compose up -d --build
curl -OJ http://127.0.0.1:13430/download/second-stain.zip
```

## Условие (для игроков)

**RU:** На часах министра остался журнал работы странного автомата.
Прочитайте последнее сообщение до того, как журнал будет стёрт.

**EN:** A minister's watch retained the log of a strange automaton. Read its
final message before the log is erased.

## Решение

1. Распаковать `second-stain.zip`: внутри `last_log.vm` (захваченный байткод),
   `watch_runtime.py` (валидатор) и `README.txt`.
2. Запуск валидатора только отвечает accepted/rejected. Чтение
   `watch_runtime.py` даёт семантику опкодов: `0x10 <byte>` загружает
   закодированный байт, `0x20 <index>` связывает его с позицией в
   сообщении; терминатор — `0xff`.
3. Байткод — повторяющиеся 4-байтовые записи
   `(0x10, encoded, 0x20, index)`, где
   `encoded = plain ^ ((index*17+31) & 255)`.
4. Инвертировать XOR по каждой записи — полученный `candidate` и есть
   персональный флаг. Никакого перебора/оракула не требуется: опкоды и
   преобразование полностью определены поставляемым рантаймом.

Архив генерируется при старте из текущего `CTF_FLAG`; в образе и
репозитории флага нет.

## Проверка решения

```bash
python3 solve.py   # скачивает архив с 127.0.0.1:13430 и печатает флаг
```
