КОНВЕРТ 3 из 5 — «просто почитать»
===================================

Ты в rbash (restricted bash): cd запрещён, слэши в именах команд
запрещены, вывод в файл не перенаправить, PATH не сменить.

Из «человеческих» программ тебе оставили только less.

ЦЕЛЬ: запустить /usr/local/bin/nextkey — он напечатает ключ
(пароль от level4; вход: ssh level4@<тот же хост и порт>).

ПОДСКАЗКА 1: открой этот файл в less и продолжай читать:
                  less README.txt
ПОДСКАЗКА 2: у less есть команды, начинающиеся с восклицательного
              знака. man less, раздел про «!».
ПОДСКАЗКА 3: внутри less набери   !/bin/sh   и нажми Enter.
              (PATH урезан, поэтому — абсолютный путь.)
              Из получившегося shell запусти /usr/local/bin/nextkey.
              Вернуться в less — exit. Быстрый вариант:
                  !/usr/local/bin/nextkey

Ключевые слова: less escape restricted shell, GTFOBins less.
