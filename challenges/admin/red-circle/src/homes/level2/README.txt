КОНВЕРТ 2 из 5 — «редактор добрый»
===================================

Ты в rbash (restricted bash): cd запрещён, слэши в именах команд
запрещены, вывод в файл не перенаправить, PATH не сменить.

Зато можно запускать vim.

ЦЕЛЬ: запустить /usr/local/bin/nextkey — он напечатает ключ
(пароль от level3; вход: ssh level3@<тот же хост и порт>).
Из rbash напрямую он не запустится — нужен полноценный shell.

ПОДСКАЗКА 1: vim сам является «хостом» для shell-команд.
ПОДСКАЗКА 2: набери внутри vim  :sh   и нажми Enter — получишь
              полноценный shell (вернёшься командой exit).
ПОДСКАЗКА 3: ещё вариант —  :!/bin/sh  или сразу
              :!/usr/local/bin/nextkey
              (помни: PATH урезан, поэтому в командах указывай
              абсолютные пути).

Ключевые слова: vim escape restricted shell, GTFOBins vim.
