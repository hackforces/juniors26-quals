КОНВЕРТ 1 из 5 — «awk наружу»
==============================

Пять конвертов, помеченных красным кругом. Каждый заперт своей
оболочкой; ключ к следующему — внутри предыдущего.

Ты попал в rbash (restricted bash). Такая оболочка не даёт:
  * делать cd;
  * запускать команды, в имени которых есть слэш (/bin/sh нельзя);
  * перенаправлять вывод в файлы (echo x > file нельзя);
  * менять или сбрасывать PATH и SHELL.

Твой PATH указывает в /home/level1/bin — загляни туда (ls bin).
Каждая утилита из PATH запускается БЕЗ ограничений rbash:
ограничения — это правила самого bash, а не системы.

ЦЕЛЬ: запустить /usr/local/bin/nextkey. Он напечатает ключ —
пароль от level2. Следующий вход: ssh level2@<тот же хост и
порт>, пароль — этот ключ.

ПОДСКАЗКА 1: в bin лежит интерпретатор awk.
ПОДСКАЗКА 2: у awk есть функция system("команда").
ПОДСКАЗКА 3: man awk, поиск по слову system.

Ключевые слова для гуглежа: rbash escape, GTFOBins.
