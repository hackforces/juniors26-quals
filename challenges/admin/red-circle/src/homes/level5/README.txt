КОНВЕРТ 5 из 5 — «защищённая картотека»
========================================

Пятый конверт — КАРТОТЕКА v1.0, самописный «защищённый» интерфейс.
Разрешены только: ls, date, whoami, find, help, quit.
Просто так запустить /usr/local/bin/nextkey не выйдет.

ЦЕЛЬ: запустить /usr/local/bin/nextkey — он печатает флаг.

ПОДСКАЗКА 1: пункт find ищет файлы в /home/level5, например:
                  find -name '*.txt'
ПОДСКАЗКА 2: меню передаёт find ТВОИ аргументы без проверки.
             Прочитай man find — там есть «опасные» опции.
ПОДСКАЗКА 3: опция -exec у find запускает произвольную команду
             для каждого найденного файла. Не забудь
             терминатор:  ;  (перед ним пробел).

Ключевые слова: find -exec escape, аргументная инъекция.
