# Screenshot / Скриншот (forensic/medium)

- Порт: `13446` (переопределяется через `PORT`; внутри контейнера `7777`, nc)
- Флаг: только из env `CTF_FLAG`
- Хэндаут: `public/medium-screenshot-files.zip` (git lfs) —
  запись ПЭМИН монитора, статичная и одна для всех: на экране виден только код
  запуска, но не флаг, поэтому запись можно раздавать как есть
  (`.cf32` — комплексный float32, HackRF).

## Материалы

- `public/medium-screenshot-files.zip` — архив с записью
  (`*.cf32`, сырые комплексные отсчёты float32 HackRF). Параметры записи
  закодированы в имени файла: `20000000SPS` — 20 Мвыб/с, `589000000Hz` —
  центральная частота 589 МГц (гармоника тактовой частоты пикселей монитора).
- `nc <ip> 13446` — сетевой «замок микроволновки».

## Описание

Классический TEMPEST / Van Eck phreaking: монитор излучает слабый
радиосигнал, промодулированный выводимой картинкой. На экране босса открыт
контроллер замка микроволновки с кодом запуска (строка из 18 символов, регистр
важен, есть спецсимвол), но увидеть его можно, только восстановив развёртку.
Задача в два этапа:

1. **Восстановить картинку**: понять, что это утечка монитора 1920×1080 @ 60 Гц,
   и снять изображение в TempestSDR.
2. **Снять замок**: отдать прочитанный код сервису — он вернёт флаг.

Код на экране — не флаг, а «ключ» ко второму этапу; поэтому `grep`/`strings`
по записи ни кода, ни тем более флага не находят: код существует лишь как
промодулированная по растру амплитуда.

## Решение

### Этап 1. Восстановить экран (TempestSDR)

1. Распаковать архив → файл `*.cf32`.
2. В TempestSDR выбрать источник *From file*, формат **float32** (complex
   float, `cf32`), Sample rate **20000000**.
3. Выставить разрешение **1920×1080**, частоту кадров **60 Hz**; подстроить
   частоту до долей герца (реальный монитор идёт на ~59.99 Гц), сдвиг по
   фазе/строке, lowpass и усиление, пока кадр не «встанет».
4. На тёмном фоне проявится окно контроллера замка и крупная строка с кодом
   запуска. Горизонтально картинка сжата (20 Мвыб/с на 1920 px ширины):
   мелкий интерфейс размыт, крупный код читается.

Подробный разбор — [WALKTHROUGH.md](WALKTHROUGH.md).

### Этап 2. Снять замок

```sh
nc <ip> 13446
# Коды запуска микроволновки: <код с экрана>
# -> Замок снят! ... Ваш флаг: ...
```

## Защита от непредусмотренных решений

- Флаг существует только в окружении контейнера; в записи его нет и быть
  не может — `grep`/`strings` по `.cf32` бесполезны.
- Код запуска не хранится строкой в записи: он «нарисован» генератором на
  экране, восстановить его можно только синхронизировав растр.
