# Дело о знаке четырёх / The Sign of Four (pwn/medium)

- Порты: `13427` (nc, интерактив; `PORT`) и `13441` (http, хэндаут; `PORT_HTTP`)
- Флаг: только из env `CTF_FLAG` (кладётся в `/run/case/flag`, читается
  только функцией `keeper`)
- Хэндаут: `http://<host>:13441/medium-the-sign-of-four-files.zip` — тот же ELF, что в сервисе

## Запуск

```bash
CTF_FLAG='InnoCTF{...}' docker compose up -d --build
nc 127.0.0.1 13427
```

## Условие (для игроков)

**RU:** На терминале сокровищ Агры можно оставить короткую подпись. Добейтесь,
чтобы хранитель признал вас участником экспедиции.

**EN:** Agra's treasure terminal accepts a short signature. Make its keeper
recognise you as a member of the expedition.

## Решение

1. Бинар собран `-O0 -fno-stack-protector -no-pie -Wl,-z,norelro`, но
   переполнения не требуется: уязвимость — `printf(signature, &expedition)`
   с пользовательской строкой формата.
2. `expedition` — глобальная `volatile unsigned short`; она передаётся в
   `printf` первым (и единственным) vararg-аргументом.
3. Пейлоад `%1$4919c%1$hn` полностью позиционный: `%1$4919c` выводит ровно
   4919 (`0x1337`) символов, `%1$hn` записывает количество выведенного как
   short по первому аргументу — то есть в `expedition`.
4. Проверка `expedition == 0x1337` проходит, вызывается `keeper()`, которая
   читает `/run/case/flag` и печатает флаг.

Индекс стекового слота стабилен в поставляемом контейнере; по attachment
устанавливаются глобальный маркер, значение сравнения, архитектура и
хардинг. Соединение per-connection (`socat ... fork`), сервис под
непривилегированным `ctf`.

## Непредусмотренные решения и потенциальные проблемы

1. Флаг в памяти процесса не лежит (`keeper` читает его с диска), поэтому
   утечка через форматную строку (`%s`, `%p`) невозможна — доступна только
   запись `%n`.
2. Альтернативные пути той же уязвимости: сборка no-PIE с `-Wl,-z,norelro`
   делает GOT перезаписываемым, а адреса известны из хэндаута — например,
   `%hn`-запись адреса `keeper` в GOT `puts` (вызывается сразу после
   `printf`) даёт флаг без трогания `expedition`; запись в `expedition`
   не-позиционными `%hn` тоже возможна (нужен слот на стеке, он стабилен
   в поставляемом контейнере). Это тот же класс «форматная строка»,
   отдельного закрытия не требует.
3. `%99999999c` и подобные подвешивают `printf`, но соединение
   per-connection — на других игроков не влияет.
