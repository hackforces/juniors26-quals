# Дело о рыжем интерфейсе / The Red-Headed Interface (web/medium)

- Порт: `13436` (переопределяется через `PORT`; внутри контейнера `8080`)
- Флаг: только из env `CTF_FLAG` (отдаётся `/api/card` профилю `archivist`)

## Запуск

```bash
CTF_FLAG='InnoCTF{...}' docker compose up -d --build
open http://127.0.0.1:13436/
```

## Условие (для игроков)

**RU:** В новом интерфейсе Союза рыжих исчезла карточка клиента. Восстановите
утерянную запись из картотеки бюро.

**EN:** A client card has vanished from the Red-Headed League's new interface.
Recover the record lost in the bureau's card files.

## Решение

Четыре ограниченных наблюдения — без словарей и перебора:

1. Главная страница («попробуйте старые забытые инструкции роботов,
   прежде чем звать оператора») отсылает к легаси-правилам обхода.
2. `/old/robots.txt`: забытые после переделки сайта правила обхода,
   среди них `Disallow: /console` — раскрывают операторскую консоль
   (классический `/robots.txt` отвечает тем же; на стенде его может
   подменять глобальный конфиг Angie — потому и «легаси-копия»).
3. `/console` сообщает все три нестандартных факта: закрытая карточка
   живёт на `/api/card`, превью-запросы маршрутизируются заголовком
   `X-Case-Role`, профиль `archivist` может видеть закрытую карточку, а
   старый клиент распаковывал успешные ответы из Base64.
4. Запросить карточку и декодировать:
   `curl -s -H 'X-Case-Role: archivist' http://127.0.0.1:13436/api/card | base64 -d`

## Проверка решения

```bash
python3 solve.py   # проходит весь путь против 127.0.0.1:13436
```
