Задача A. Среднее двух чисел

Жюри уверяет, что флаг прячется в служебных заголовках исходящих запросов системы.

Сервис хранит два числа. Напишите решение на Lua, которое:

  1. получит data1 с {{ base }}/system/data1;
  2. получит data2 с {{ base }}/system/data2;
  3. посчитает среднее (data1 + data2) / 2;
  4. отправит результат POST-запросом на {{ base }}/system/out.

Доступна функция fetch(url [, method [, body]]). По умолчанию метод GET. Разрешены только URL, начинающиеся с http://127.0.0.1.

Решение проверяется на наборе тестов. Вердикт — Accepted, если все тесты пройдены.
